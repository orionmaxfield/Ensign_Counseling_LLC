# Launch Checklist

## Before build
- [ ] BRIEF.md complete; name/address/phone match Google exactly
- [ ] Domain purchased (Cloudflare Registrar)
- [ ] Google Business Profile started (verification takes days–weeks)

## Build
- [ ] All {{PLACEHOLDERS}} replaced (search for "{{")
- [ ] One page per specialty, each with city in h1 and title
- [ ] Photo added, under 300 KB
- [ ] sitemap.xml lists every page with the real domain
- [ ] Form tested
- [ ] Checked on a phone

## Host
- [ ] Repo connected to Cloudflare Pages (preset None, output /)
- [ ] Custom domain added, HTTPS padlock showing
- [ ] GitHub Pages turned off if it was on

## Launch
- [ ] Search Console: domain property verified via DNS, sitemap submitted
- [ ] Google Business Profile: website link, hours, specialties, photos
- [ ] Psychology Today profile live, linking to site
- [ ] GoodTherapy / TherapyDen / insurance directories
- [ ] Name, address, phone identical everywhere

## Monthly
- [ ] Google Business Profile performance screenshot
- [ ] Search Console performance screenshot
- [ ] One improvement shipped
